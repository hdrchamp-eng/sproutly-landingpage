# Community preview

Design update, 5 November 2026. Submission is deliberately preview-only: no request, persistence, email or automatic publication. The form validates input and explicitly says it has not been sent. Published community ideas still use the existing moderated public query. No example votes or invented community contributions are displayed.

Future workflow requested by owner: idea or poll proposal → private admin review → explicit approval → public idea or poll. Admin sets poll options and start/end timestamps. Only approved polls within that interval accept votes. After closing, generate a summary for the admin. Intended correspondence recipient: info@sproutly.co. Delivery, authorization, vote integrity, persistence and reporting are deferred, not implemented by this design update. No admin login is exposed on the landing page.
